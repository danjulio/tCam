Resolution
The sensor is 160×120; higher settings interpolate the thermal data bilinearly before coloring, like the desktop application. Saved PNGs use the selected resolution.
Temperature range
Auto range tracks the scene, smoothed to avoid flicker. Locking copies the current span into manual limits — useful to watch one thing heat up.
Cursor
Probe reads the tapped pixel on this screen only. Move spot repositions the camera's own spot meter, which is measured by the sensor itself.
Isotherm alarm
Pixels at or above the threshold are painted in a fixed alarm color regardless of palette — the fastest way to see "anything hotter than X" at a glance.

Capture
Raw saves the camera's own json frame (.tjsn), the same format the desktop application writes, so existing analysis tools read it.
Recordings and screenshots save to this device's Downloads folder — the camera has no storage of its own. A recording is written when you press stop; closing the tab mid-recording discards it. Note the "sign in to network" popup browser cannot save downloads — for recording, open the camera's address in your normal browser instead.
Camera identity
Also the access point name and the mDNS hostname.
Cameras on this network
The camera asks the network over mDNS — nothing is scanned or contacted until you press the button, so it costs the live stream nothing. Selecting a camera opens its interface.
Install as an app
Installs a home screen icon that opens this camera directly, without browser chrome.
Join a network
A fixed address is worth setting if you install this app to your home screen: the installed icon opens whatever address it was installed from, so a camera whose address moves has to be found again. Pick something outside your router's DHCP pool. (A DHCP reservation in the router achieves the same thing.)
Hotspot mode
Stops joining your network and makes the camera broadcast its own WiFi again, reachable at 192.168.58.1. Use this before moving the camera somewhere else.

Three other ways back, if this page is ever unreachable: the camera raises its own hotspot automatically after about a minute of failing to find its network; holding the button on the board for five seconds resets networking to hotspot mode; and while on your network it is also reachable at tcam-mini.local.

In access point mode the signal shown is the strongest connected device — usually whichever one is closest. In station mode it is the camera's own link to your network; below about −75 dBm, raise the frame interval on the Camera tab.
Firmware update
The camera writes to the spare partition and only switches to it once the whole image is received and verified — an interrupted update leaves the current firmware running.
Security
The camera also serves this interface over HTTPS on port 443 with a certificate it generated for itself (valid to 2050). Your browser will warn once per device because the certificate is self-signed — that is expected for a device with no public name; accept it to continue.

Video over HTTPS: some browsers accept the certificate for pages and settings but refuse to apply it to the encrypted video stream (WebSockets). If the settings work over HTTPS but the image never appears, that is your browser's policy, not a camera fault — use the HTTP address for viewing; the UI offers the switch automatically.
